# Hackatón — La Palanca

Pedidos y reparto de La Palanca (Siracusa, 14/11/2026).

- `datos/` — material recibido en el nivel 1 (catálogo, padrón, lugares, clientes, historial, WhatsApp)
- `datos/nivel-2/` — material recibido en el nivel 2 (pedidos, flota, operación, mapa)
- `nivel-1/pedidos.json` — entrega del nivel 1
- `nivel-2/rutas.json` — entrega del nivel 2
- `nivel-2/codigo/` — código que genera y controla `rutas.json`, con sus instrucciones de uso
